## LinkedIn Projects description

> Designed and built AI Procurement Copilot v1.2, a governed procurement decision-support portfolio using Python and Streamlit. The application supports RFQ validation, category-aware supplier comparison, cost and risk evaluation, scenario and negotiation analysis, executive outputs and controlled downloads. Version 1.1 also established a read-only ERP workbook preview with structural and package-safety checks. The project keeps final sourcing decisions under human control and does not claim live ERP integration, production deployment or realized savings.
